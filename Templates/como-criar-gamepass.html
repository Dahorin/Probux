Como Criar um Gamepass Público

Aprenda a criar uma Gamepass e deixá-la pública para compra

1

Crie sua Gamepass

Para criar uma Gamepass no Roblox:

  1. Acesse o Roblox Studio com sua conta
  2. Vá em Game Explorer (Explorador de Jogos)
  3. Clique com o botão direito no jogo desejado
  4. Selecione "Add Game Pass" (Adicionar Gamepass)
  5. Faça upload de uma imagem para a Gamepass
  6. Dê um nome e preço para a Gamepass
  7. IMPORTANTE: Desmarque a opção "Use regional pricing" (Preço regional) ou "Preço Regional", pois isso fará o preço variar conforme a localização e causará erro na compra!
  8. Clique em "Create" (Criar)

Atenção: O preço deve ser fixo! Se o "Preço Regional" estiver ativado, o valor pode mudar automaticamente e nosso sistema não conseguirá verificar o preço correto.

2

Torne a Gamepass Pública

IMPORTANTE: Não basta tornar a Gamepass pública - o MAPA onde a Gamepass está deve estar PÚBLICO!

Passos para tornar o mapa e a Gamepass públicos:

  1. Acesse roblox.com/my/game-passes
  2. Encontre a Gamepass que criou
  3. Clique sobre a Gamepass
  4. Verifique se o preço está definido (não pode ser gratuita para venda)
  5. IMPORTANTE: Clique no link do jogo (mapa) onde a Gamepass está
  6. No jogo/mapa, verifique se está configurado como "Public" (Público)
  7. Volte para a Gamepass e certifique-se de que está ativa e pública

Erro 404? Se o mapa do jogo estiver privado, a Gamepass ficará inacessível mesmo que ela esteja pública! O jogo (mapa) DEVE estar público.

3

Copie o Link da Gamepass

Para obter o link correto da Gamepass:

  1. No Roblox, vá à página da sua Gamepass
  2. Copie a URL da barra de endereços
  3. O link deve ser algo como:
    https://www.roblox.com/pt/game-pass/12345678/Nome-da-Gamepass
  4. Cole este link no formulário do Probux

Dica: Se aparecer erro 404, verifique se a Gamepass está pública e se o link está correto!

Dicas Importantes

  • Preço mínimo: O Roblox exige um preço mínimo para Gamepasses (geralmente 5 Robux)
  • Taxa do Roblox: O Roblox cobra 30% de taxa sobre cada venda
  • Aguarde alguns minutos: Após criar a Gamepass, aguarde alguns minutos para que fique pública
  • Verifique o link: Certifique-se de que o link contém "game-pass" e o número ID da Gamepass
